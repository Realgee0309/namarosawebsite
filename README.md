# Namarosa Hardware Website

PHP/MySQL website for Namarosa Hardware in Bungoma, Kenya. The application includes a product catalog, quote-request flow, contact information, and an admin area for managing products and enquiries.

## Project location

The website source is in [`namarosahardware/`](namarosahardware/). See the [application README](namarosahardware/README.md) for setup instructions, application features, and configuration details.

## Technology

- PHP with PDO
- MySQL
- HTML, CSS, and JavaScript
- Apache-compatible hosting

## Deployment note

Review the application README before deployment. Replace any sample credentials, configure database secrets outside tracked files where possible, enable HTTPS, and remove or change any default administrator password before making the site public.
